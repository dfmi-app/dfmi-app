- 恢复后的 passkey：会话恢复时间同时限制凭据注册时间。恢复前的、时间缺失或不合法的凭据不能取得新会话。只有钱包签名认证的同一所有者能重新登记自己的旧凭据；passkey 会话不能完成该操作。
- 会话持久化：写入或删除失败不再返回成功。每次认证都读取权威会话及地址撤销记录，避免另一个实例继续信任缓存。
- 邮件写入：会话、准备记录、正文、发件记录、联系人、已读、星标及删除操作的持久化失败不会被成功响应掩盖。
- 邮件读取：七类对象列表跟随全部分页；读取失败或游标缺失、循环时返回错误，不把不完整邮箱作为成功结果。详情直接读取持久化数据，恢复后不依赖内存预热。
- 附件：MIME 邮件提供元数据和带认证的二进制下载入口，保持原始解码字节、编码 UTF-8 文件名，并设置 attachment、nosniff、CSP 和 private/no-store。详情及附件共用钱包访问与删除标记检查。
- 访问隔离：缓存、原始邮件的 From 头、登录表单自填名称及展示元数据都不能单独授予读取权限。邮箱别名只采用配置或解析器确认的映射；钱包地址形式的名称不得冒充另一个钱包。

## 恢复操作要求与尚未验收的证据

1. 恢复前停流量或关闭所有实例，恢复后在每个实例的持久环境中设置 SESSIONS_NOT_BEFORE，再开放访问。重新部署时不得丢失该值。验证旧 token 及被删除的旧 passkey 无效，新钱包签名登录和重新登记后的 passkey 有效。
2. 所有恢复前 passkey 都需要钱包签名后重新登记，包括从未删除的凭据。这是防止旧备份丢失撤销记录后凭据复活的保守策略。
3. 提供真实云端隔离桶恢复的恢复点、对象数量/字节数/SHA-256、版本与删除标记处理、跨区域副本、备份覆盖清单、IAM/KMS 权限、RPO/RTO 和脱敏操作日志。本地文件模拟不证明 AWS 备份、复制或运维步骤已执行。
4. 真机 iPhone/Safari 与 Windows Hello 仍需独立验收，开发方先前自测不能替代这一点。链上 ENS 归属变更与解析缓存新鲜度也未被本地配置名称测试覆盖。
5. 认证读取增加、完整前缀扫描、MIME 附件在内存中解析的生产容量、索引、流式处理与大小限制需要验证。
6. SES 可能先接受发送，随后发件记录写入失败。此时接口返回错误并标记 deliveryMayHaveOccurred；不要自动重发。可靠 outbox/幂等投递不在此补丁范围内。
