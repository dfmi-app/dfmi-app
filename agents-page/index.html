A selling agent invoices and verifies settlement on the dfmi chain. A buying agent pays from a session key its owner granted, inside a cap the wallet contract enforces. Everything below is read from the ledger and the chain. The orange rows are the only moments a person acted.

Grant. The owner funds a SessionKeyWallet and grants a session key a cap and an expiry. That is the first human action.

Trade. The buyer agent asks the seller for an offer, checks its budget on-chain, requests an invoice, pays through the facilitator with no gas, and collects the goods. The seller agent releases goods only after it sees the exact amount settled on-chain. No prompt decides any of that; code and the contract do.

Revoke. One transaction from the owner and the key on the buyer's machine can no longer spend a cent. That is the second human action.
